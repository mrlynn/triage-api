# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and argue about the code rather than
about the person. Harassment of any kind is not tolerated.

Report problems by opening a private security advisory or contacting the
maintainer directly. Reports are handled confidentially.
